# Contributing to AI Study Assistant

Thank you for your interest in contributing to **AI Study Assistant**!

This is a community-driven open-source project focused on building a practical AI-powered study assistant while giving contributors real experience in software development and AI Engineering.

We welcome contributors of all experience levels.

---

## 📌 Before You Start

Before contributing, please:

1. Read this document completely.
2. Read the project's `README.md`.
3. Check existing Issues and Pull Requests.
4. Look for issues labelled `good first issue` if you are new.
5. Ask questions in the appropriate community discussion channel when something is unclear.

Please avoid starting major features without discussing them first.

---

## AI USAGE POLICY

AI tools are becoming an important part of modern software development. However, this project is also intended to help contributors learn and develop their own engineering skills.
Therefore, we have a specific policy regarding AI-assisted development.

Acceptable AI Usage
AI tools may be used for learning and understanding.
Examples include:
Asking an AI to explain a programming concept.
Asking why an error is occurring.
Asking for an explanation of an unfamiliar function or library.
Using AI to understand documentation.
Asking conceptual questions about algorithms or AI/ML techniques.
Using AI as a learning assistant while studying a problem.
For example:
"Explain how vector embeddings work."
is acceptable.

AI-Generated Code
Generating code with AI for direct submission to this project is not applicable/allowed.
Contributors should write the code they submit themselves.
Do not:
Ask an AI to implement an issue and submit the generated code.
Copy/paste AI-generated functions into a Pull Request.
Ask an AI to generate an entire feature.
Generate a solution with AI and submit it as your own implementation.
Use AI to substantially rewrite your implementation and then submit the generated result.
For example:
"Implement the PDF extraction module for this project."
and then submitting the generated code is not allowed.
Why?
The purpose of this project is not only to produce software.
It is also a learning and engineering initiative.
We want contributors to develop the ability to:
Understand problems
Design solutions
Write code
Debug their own implementations
Read documentation
Review code
Make engineering decisions
If AI writes the implementation, contributors can miss the very skills this project is designed to develop.

## CODE OWNERSHIP

Every contributor is responsible for understanding the code they submit.
During code review, contributors may be asked to explain:
Why they chose a particular approach.
How their implementation works.
Why a particular library was used.
How edge cases are handled.
How the code could be improved.
If you cannot explain your submitted code, it should not be submitted.
